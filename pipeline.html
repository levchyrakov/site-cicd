Как устроен пайплайн

Workflow описан в файле .github/workflows/deploy.yml и состоит из двух заданий (job). Второе задание запускается, только если первое завершилось успешно.

  1. Событие push

    Любой коммит в ветку main запускает workflow «Deploy static site».

  2. Job lint

    На виртуальной машине ubuntu-latest устанавливается Node.js, затем HTMLHint проверяет все HTML-страницы, а Stylelint — файл стилей. При ошибке пайплайн останавливается и сайт не обновляется.

  3. Job deploy

    Файлы сайта копируются в папку _site, в подвал страниц подставляются номер коммита и время сборки, после чего артефакт публикуется на GitHub Pages.
