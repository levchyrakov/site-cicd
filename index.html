Обновлено через CI/CD — версия после изменения

Это статический сайт, который публикуется на GitHub Pages автоматически: после каждого push в ветку main запускается workflow, проверяет код и выкладывает новую версию.

1. Push

Изменения отправляются в репозиторий на GitHub.

2. Проверка

Линтеры HTMLHint и Stylelint проверяют разметку и стили.

3. Деплой

Сайт собирается и публикуется на GitHub Pages без ручных действий.
